# Security policy

## Supported versions

Security fixes are applied to the current supported release line, currently PolyBot 2.2.x. Users should upgrade to the latest available version in that line.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Use GitHub's **Report a vulnerability** feature on the repository's Security tab to send a private report to the maintainers. Include the affected version or commit, steps to reproduce, and any relevant logs or proof of concept. Avoid including real credentials or private user data.

Maintainers will acknowledge reports as soon as practical, investigate the impact, and coordinate a fix and disclosure with the reporter. Please allow time for a fix before sharing vulnerability details publicly.
